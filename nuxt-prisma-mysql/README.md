# تاجر برو — TajirPro (Nuxt 3 + Nuxt UI + Prisma + MySQL 8.0)

نسخة متكاملة مبنية بتقنيات **Nuxt 3 + Nuxt UI + Prisma + MySQL 8.0** ومجهزة بالكامل للنشر المباشر على **Vercel** أو التشغيل التلقائي على جهازك:
- نقاط بيع (POS) سريعة تدعم تسعير الجملة ونصف الجملة والقطاعي، العروض الترويجية، نقاط الولاء، والتحصيل المتعدد/المجزأ بين الخزائن (كاش، إنستا باي، فودافون كاش، فيزا، آجل).
- تتبع التشغيلات وتواريخ الصلاحية (FEFO)، الأرباح التاريخية المجمدة وقت البيع، والمرتجعات الكلية والجزئية.
- عروض الأسعار (Quotations) والتحويل الفوري لفاتورة، وفواتير المشتريات ومرتجع الموردين.
- الخزائن والتحويلات بينها، المصروفات والمصروفات المتكررة، كشوف حسابات العملاء والموردين.
- تقارير الأرباح والخسائر (P&L)، تحليل الأصناف الراكدة ABC، محاكاة ماذا لو (What-If)، حصص الشركاء، تنبيهات المالك الذكية، وإعادة الطلب الآلي.
- مصادقة جلسات موقعة (`HMAC-SHA256`) + صلاحيات الموظفين (`RBAC`) + تقفيل الوردية (6 بنود) + سلسلة تحقق الفواتير (`SHA-256`).

---

## 1) التشغيل التلقائي على جهازك (بنقرة واحدة)
بعد فك ضغط المشروع وتثبيت **Node.js 22 LTS**:
- **على ويندوز:** انقر نقراً مزدوجاً على `START-WINDOWS.bat`
- **على ماك أو لينكس:** انقر نقراً مزدوجاً على `START-MAC-LINUX.command`
- **أو عبر سطر الأوامر:** `npm run auto`

سيقوم المشغّل التلقائي بنسخ `.env` وتثبيت الحزم وتشغيل حاوية MySQL عبر Docker (إذا كانت متاحة) وتهيئة الجداول والبيانات الأولية ثم فتح المتصفح على `http://127.0.0.1:3000`.

---

## 2) النشر المباشر على Vercel
1. جهّز قاعدة بيانات **MySQL 8.0** سحابية (مثل Aiven أو PlanetScale أو TiDB Cloud أو MySQL على خادمك الخاص).
2. ارفع مجلد المشروع إلى GitHub واربطه في [Vercel](https://vercel.com) (**Add New → Project**).
3. أضف متغيرات البيئة التالية في **Vercel → Project Settings → Environment Variables**:
   - `DATABASE_URL`: رابط اتصال MySQL 8.0 الكامل (`mysql://USER:PASSWORD@HOST:3306/tajirpro_pos?sslaccept=strict`).
   - `NUXT_SESSION_SECRET`: نص سري عشوائي (32 حرفاً فأكثر) لتوقيع جلسات الدخول.
   - `NUXT_LICENSE_SECRET`: نص سري عشوائي لتوقيع التراخيص وسلسلة الفواتير.
4. قبل أو بعد أول نشر، نفّذ تهيئة الجداول والبيانات الأولية مرة واحدة ضد قاعدة البيانات:
   ```bash
   npx prisma db push
   npm run db:seed
   ```
5. يتعرف Vercel تلقائياً عبر `vercel.json` و`nuxt.config.ts` على إعداد `preset: 'vercel'` ويستخدم أمر البناء `npx prisma generate && npm run build`.

---

## 3) النشر عبر Docker Compose (MySQL + Nuxt)
```bash
docker compose up -d --build
```
سيعمل التطبيق على المنفذ `3000` متصلاً بقاعدة بيانات MySQL 8.0 تلقائياً.
